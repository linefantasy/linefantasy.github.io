# LineTop 长期产品约束

本文件是长期产品约束的唯一正式来源；唯一当前设计入口为 [根目录 design.md](../design.md)，当前任务/授权与证据时效见 [WORK_STATUS](WORK_STATUS.md)。具体字形、尺寸、进度参数在设计文档中管理，不复制源码和流水日志。

现行要求以2026-11-01最新补充为准：浅深两主题、全部八场景均改背景；桌面贯穿条带，手机可局部裁切但倾角一致；侧栏按阅读顺序排列。固定头像、右下齿轮、艺术字与太阳接力继续保留。本轮交付后等待新指令。文件不覆盖系统规则或用户后续指令。

## 1. 用户明确要求（现行）

### 身份、文案与真实内容

- 网站为 LineTop，域名 linetop.top；保留 CNAME 和真实 GitHub <https://github.com/linefantasy>，不擅自更改 DNS、提交、推送或部署。
- 主内容为欢迎 → 个人展示 → 关于 → 项目占位 → 故事 → 喜好 → 工具 → 页脚。故事、喜好、工具是同一页的主场景，接入唯一滚动控制器，不开浮窗或新窗口。探索进入个人展示；不扩展为完整多页业务。
- 首版内容精简，项目最多两项，明确“筹备中/持续更新”；不虚构故事、经历、作品、成果、数据或社交账号。喜好只用用户已有事实，故事没有素材可明确待整理。
- 欢迎默认使用 `Hello, welcome to`，这是允许调整的实施文案，不增其他口号。原身份整行必须替换成精确文本 `line fantasy`；侧栏名字为 `line`，不能将两者混用。
- 删除首页 SCROLL TO DISCOVER、从一个想法开始、向下，还有更多及其标点变体、一个不断生长的个人空间。删除 SOFTWARE / AI / EVERYDAY CURIOSITY、STILL EXPLORING ↗ 等同类装饰英文小字；不误删 LineTop、line fantasy、真实 GitHub 名称、有意义内容和源码作者注释。
- 删除所有区块左上装饰页码、专用下划线与空占位；保留有意义标题、状态、正文数字和路由。新增场景不生成页码。

### 艺术字与颜色

- 首页 LineTop 必须有真正的艺术字设计，不能仅普通字体平铺、改颜色或斜体。Top 三个字母明显融入既定辅色，可用定制字形、实心/描边、切割、嵌色等办法，保持清晰可读。
- 浅色以 #FFFFFF 为基底，辅色 #D9FF00、#4FFFC4、#31A9FF；最新明确要求浅色和深色全部八场景都改背景，替代此前“本轮浅色实际效果完全不变”的限制。首次默认浅色，深色主背景明确为 #000000，偏好本地保存；可调整深色正文/表面/边界/焦点保证可读。艺术字资产保留，侧栏保持辅色主导。
- 少量斜置辅色粗线条参与侧栏/艺术字构图，不遮挡内容，不把三种辅色平均堆满画布。不引入紫、橙、粉等无关主题色，不复制旧深色光晕/彩虹渐变。
- 桌面欢迎条带贯穿画布，后续场景保持低密度局部裁切；手机重新绘制，允许不贯穿，但倾角与桌面一致。所有界面都适配，背景不拦截输入、不循环动画、不穿过艺术字内孔或遮挡正文/太阳/设置。固定22°及具体尺寸是Agent实施选择，非用户永久冻结值。
- 使用语义主题变量，浅色不全局反色，深色不覆盖字面色常量来误改所有组件。主题切换不重置场景、URL、焦点或太阳；尽早应用保存主题并同步 color-scheme/theme-color。小字与必要边界对比度需验证。
- 具体艺术字已有第三阶段本地运行截图，但尚无用户视觉认可；不能把 Agent 的候选字形、颜色分配或尺寸写成用户已认可。

### 转场、太阳与输入

- 欢迎文字在原始屏幕位置逐渐消失，下一屏在自己的最终位置逐渐显现；不大字左滑出，不下一屏从底部滑进，正常动效模式不显示整屏纵轴滑入滑出。
- 其他区块之间可克制交叉淡化/遮罩，避免整页上下滑动的视觉表现。原先“不接受仅各区块普通淡入”不能被用来拒绝本次明确的原位显隐要求；本次仍需要共享舞台、连续进度与太阳接力，而非独立观察器随意淡入。
- 优先原生滚动驱动 sticky 舞台；保留输入，不默认吞滚轮、强制整屏翻页或补播锁屏。普通内容阅读滚动与整屏滑动转场必须区分。
- 保留首页右上现有黄绿色太阳/齿轮图形及接力作用；可移动旋转并连续落到个人展示正确位置，不能因文字淡化而漂移、闪现、重复或丢失。
- 保留“向下探索”。点击必须经过与手动滚动相同的连续转场；不能瞬间跳下一屏，也不能仅 smooth scroll 把页面向上搬走。设计须覆盖中途点击、快速/反向滚动、窗口缩放和直接锚点。
- 尊重 prefers-reduced-motion。无 JavaScript、初始化失败、减少动态、短屏或高倍缩放时允许回退可读自然文档；主内容不能永久隐藏或停在屏外。回退模式不冒称正常动效完成。

### 导航、固定头像与右下设置

- 左侧纵向导航从首页起可见，**替代原顶部导航**；顶部头像框和名字 line，六项依次为**探索、关于、项目、故事、喜好、工具**，不添加首页或设置。探索指向个人展示，line回首页；窄屏同一份侧栏DOM。不为“等等”无限扩展菜单。
- 最新明确要求：侧栏外缘不画黑色分隔边线，包括桌面右边、手机抽屉右边和窄屏自然文档底边；头像框、必要按钮边界和焦点提示保留。
- 侧栏栏目均为真实锚点，接入统一场景/历史/焦点与当前项；故事/喜好不再是面板。工具没有真实可用内容时明确筹备中，不虚构工具或链接。
- 窄屏明确收起方式及设置打开方式，避免挤压主标题或两套重复导航；必要的键盘、触屏、焦点和可读性改进可自主补充。
- 头像固定使用根目录用户图片：当前为 `头像1.jpg`。保留头像框、裁切和默认图失败后备；头像不可点击修改。删除上传/预览/保存/恢复界面和旧头像脚本，不读或清理旧 IndexedDB 头像，不影响其他偏好。
- 右下固定齿轮替代旧设置面板：默认只显示齿轮，hover/focus/点击可展开两个图标按钮（主题、动态）；有随状态变化的tooltip与可访问名称，支持触屏、键盘、Escape、外部关闭。齿轮与太阳是独立元素；不无限旋转，不遮挡操作。系统减少动态优先，仍可使用工具栏。主题/动态保存失败时当前访问可用且如实提示。无账号/后台/上传服务。

### 技术、来源与工作边界

- 优先沿用静态 HTML/CSS/JavaScript，不换框架、不默认加动效库。改动应理解并复用现有实现，不为理解不足而全量重做。
- 适合的 Uiverse 组件真实复用实际源码，保留作者来源和核心交互；当前实际复用 7、4、18、20；原条目3复选框已随设置结构退役，源码快照保留，不再声称页面使用。右下按钮真实复用20的圆形/填充/tooltip机制，齿轮与展开逻辑为新增实现。允许真实改成纵向，无法适配需解释原因，不能仿写后假称复用；不为凑组件添加业务。
- 隔离选择器、动画名和 input id/name；导航不沿用演示 radio 冒充链接，不保留假账号、价格或数字。允许修改语义/尺寸/颜色，原始快照与资料保留。
- 保留原始色板、组件整理、视频笔记和参考地址；视频回看索引不等于网页时长，不把未经核验的参考细节写成事实。
- 首版不包含复杂物理堆积、无限拖拽画布、大型 3D、完整多页、登录/付费/后台或其他无关业务。
- 每阶段开始查 Git 状态/暂存区/相关 diff，保护未提交修改与未跟踪资料。只实施当前授权阶段，报告实际完成、证据、未完成/未验证和查看方式，然后停下。
- 视觉和动画结论只能来自真正运行的对应版本与过程证据；文档通过、旧检查通过和用户认可必须区分。

## 3. 自主维护与需要明确指示的边界

在当前已授权任务和阶段内，可自主修复错误、改善可读性/无障碍/响应式及局部维护，不必为每个字号或尺寸反复提问。本轮只实施用户列出的功能及必要验证维护，保留浅色品牌视觉及核心转场；交付后停止，不自动开展新功能或上线。

超出本次明确要求的主要视觉方向、色板扩展、技术栈迁移、核心体验重选、大型功能和部署，需要新的明确指示；已明确授权的变化不重复询问。新的指令可更新约束，不能以旧设计永久冻结产品。
