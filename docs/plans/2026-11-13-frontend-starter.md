# 前端复用包实施计划

目标与方案以 [唯一设计](../design.md) 的前端复用包小节为准，用户已授权自行选择常见复用方式并实施；原站只读，不提交、推送、部署或安装依赖。

- [x] 定义ZIP导出合同：完整资源及来源、无CNAME/日志、独立解压、存储前缀一致、清单哈希、可重复生成、拒绝误覆盖和非法参数。
- [x] 新增 scripts/export-frontend.py、templates/frontend 的使用说明/组件依赖表和真实组件页模板；原站保持不变。
- [x] 生成 dist/linetop-frontend-starter.zip；独立解压，在副本执行生成器与Node检查，用浏览器验证首页/地图及组件页的设置、导航与移动布局。
- [x] 记录文件保护核对、产物位置、使用方式与限制，更新README/当前交接。

重点：不是把仓库或日志直接压缩；不遗漏样式、模块依赖或第三方来源；不承诺组件可无改动嵌入任何框架；品牌艺术字仍是原始SVG路径，修改品牌须替换两份内联字形。用户未请求公开开源，不增加自拟开源许可。
