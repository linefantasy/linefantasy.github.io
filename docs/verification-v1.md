### 对比度

计算记录：[contrast.json](../.tmp/verification/contrast.json)。

- #12354F / #FFFFFF：12.74:1。
- 次级文字 #426077 / #FFFFFF：6.62:1。
- #12354F 在黄绿色、薄荷绿与浅蓝白混色上的对比度分别为 11.08、9.97、12.00:1。
- 次级文字在上述底色上最低为 5.18:1。

axe 无法按文字描边颜色和透明下划线背景直接判定，因而留下人工检查项；已结合实际截图核对深蓝描边与白底、深蓝实心字与黄绿下划线，不把“0 个确定违规”写成所有项目自动通过。
