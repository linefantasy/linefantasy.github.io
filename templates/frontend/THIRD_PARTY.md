# 来源与第三方文件

模板保留 LineTop 的界面、示例文案和品牌 SVG，未为原项目擅自添加新的开源许可证。用于自己的项目时替换示例身份、头像和外链；公开重新分发时保留各项原始许可和来源。

Uiverse 条目 4（Pradeepsaranbishnoi）、7（doniaskima）、18（Tiagoadag）、20（wilsondesouza）为实际适配部件；条目 3（andrew-manzyk）已退役，原始快照仍保留。逐项 URL 和作者见 `public/assets/uiverse/sources.json`。Uiverse 官网声明 UI 元素采用 MIT，作者和现有注释在包内保留；参考 <https://uiverse.io/>。完整原组件整理在 docs/references。

D3 Array 和 D3 Geo 的现有许可文本分别位于 `public/assets/vendor/d3-array-LICENSE.txt`、`d3-geo-LICENSE.txt`，相应运行文件没有修改。

地图边界并非此模板原创：上游 URL、版本、SHA-256、处理口径和限制在 `public/data/maps/SOURCES.md`、manifest 与 sources 元数据中。世界来源 Natural Earth，中国/美国来源及许可按各元数据，日本派生数据包含 OpenStreetMap/Wambacher 信息，已有 ODbL 记录保留在 sources/ODbL-1.0.txt。不能将所有地图数据一概标为 MIT；本包的界面复用说明不替代原始数据许可。

本包包含已生成数据，不包含大体积上游研究下载、历史验收截图、Git 历史或原域名 CNAME。SOURCES 中原仓库验证报告的本地链接在导出副本改为历史路径文字，来源正文及实际地图数据保持；这些历史报告不代表新项目已验证。
